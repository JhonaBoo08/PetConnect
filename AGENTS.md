# PetConnect Agent Instructions

## UI/UX work

For tasks involving UI, UX, mobile interfaces, websites, dashboards, navigation, visual design, responsive layout, accessibility, typography, colors, component design, or interaction design:

1. Load the project skill `ui-ux-pro-max` from `.agents/skills/ui-ux-pro-max/SKILL.md` before proposing or implementing interface changes.
2. Follow its workflow and use its bundled local search/reference data when relevant.
3. Inspect the existing application, flows, components, and design system before changing UI.
4. Preserve existing functionality unless the user explicitly requests its removal.
5. Prefer coherent information-architecture and design-system improvements over isolated cosmetic changes.
6. Avoid unnecessary text, duplicated actions, and redundant navigation.
7. Validate affected mobile and web layouts at appropriate viewport sizes.
8. Check accessibility, touch targets, loading/error/empty states, and interaction feedback before declaring UI/UX work complete.
9. Do not change backend/API behavior solely for visual redesign unless the UI change genuinely requires it.
